# 307307 BI Methods for Generative AI

[Open the student course website](https://msfasha.github.io/307307-BI-Methods-Generative-AI/) (current semester, 20261).

A course about Natural Language Processing and Text Mining, Large Language Models, Agentic AI and AI Governance.

## Repository layout

- `20261/` - current semester (Agentic AI modules 1-6, AI Governance modules 7-11). This is what the website publishes.
  - `20261/site/` - website build (`build.py`, Quarto config, theme CSS).
- `20242/`, `20243/`, `20251/`, `20252/` - earlier semesters (not published on the website).
- `.github/workflows/publish-course.yml` - builds and deploys the website to GitHub Pages.

The website offers each module's notes (HTML/PDF), slides, extended lecture notes and labs, plus one-click
downloads of all notebooks with data and all PDFs. See [PUBLISHING.md](PUBLISHING.md) for how it is built and published.
